# Что есть в репозитории

Все блокноты лежат в experiments

## NICE

Статье [NICE: NON-LINEAR INDEPENDENT COMPONENTS
ESTIMATION](https://arxiv.org/pdf/1410.8516) посвещается блокнот nice_2d_swissroll.ipynb и nice_affine_olivetti.ipynb.

Во втором блокноте используется аффинный coupling.

## REAL NVP

Реализация статьи [DENSITY ESTIMATION USING REAL NVP](https://arxiv.org/pdf/1605.08803) находится в файле realnvp_celebA.ipynb, модель обучена на датасете celebA.
### Samples and FID

В файле generate_samples.ipynb можно сшенерировать картинки используя модели, обученные на Cifar10 и CelebA. Также можно посчитать FID для CelebA.

## Непрерывные нормализующие потоки

Реализация статьи [Neural Ordinary Differential Equations](https://arxiv.org/pdf/1806.07366) находится в cnf_simple.ipynb

## TarFlow

Реализация [Normalizing Flows are Capable Generative Models](https://arxiv.org/pdf/2412.06329) находится в NF_capable_GM.ipynb
